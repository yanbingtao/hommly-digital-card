# Hommly homepage assets

Place optimised Hommly product photography here. The homepage reads these paths automatically.

## Required / recommended files

| Path | Role | Target size |
|------|------|-------------|
| `hero-hommly-ecard.webp` | Primary hero visual: gift + QR + phone composition (no headline text in image) | 300–600 KB |
| `qr-card.webp` | Physical Hommly QR card close-up | < 150 KB |
| `gift-box.webp` | Physical Hommly gift / packaging | 100–300 KB |
| `ecard-preview.webp` | Recipient Experience section — phone + gift lifestyle preview | 100–300 KB |
| `final-cta.webp` | Final CTA box background (full-bleed inside the rounded CTA) | 100–300 KB |

## Guidelines

- Prefer WebP (or AVIF).
- Do not bake marketing headlines into images.
- Use real Hommly products only — no generic stock gifts.
- Until a file is present, the UI shows a clean neutral placeholder (not fake product art).
